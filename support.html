Support

Start with the right reset.

Membership will not unlock

  1. Confirm you selected the same edition as the Gumroad product you bought.
  2. Paste the license key from the Gumroad receipt—not the product ID or product URL.
  3. Confirm the membership is active in Gumroad.
  4. Use Plans → Restore / revalidate purchase while online.

Offline access expired

Reconnect and revalidate. Paid access has a 14-day offline grace period from the last successful Gumroad check.

Install on Android

Open Cuspr in Chrome, use the browser menu and choose Add to Home screen or Install app. Cuspr is an installable PWA, not a native APK.

Data reset

Removing site/app data deletes local profiles, caches and saved entitlements. Keep your Gumroad receipt and license key so you can restore access.
